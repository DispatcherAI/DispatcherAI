# sonner-b4ffb609

[sonner-b4ffb609](https://github.com/emilkowalski/sonner/commit/b4ffb609bd5a7e95beff26214d310e4edfc9054c) resolves a [bug](https://github.com/emilkowalski/sonner/issues/451) which broke the layer-by-layer toast disappear effect. 

Although this effect is working in <=v1.4.41, v1.5.0 introduced a variety of features and (critically) bug fixes. Until this fix is part of an official release, the postinstall script serves to install and build the library at the commit of the fix.
